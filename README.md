# Perceptron Simple para Aprobacion de Creditos

Laboratorio UCV que implementa desde cero un perceptron simple para una aprobacion preliminar de creditos.

## Ejecucion

```powershell
py main.py
py -m pytest
```

La entrada contiene dos variables: ingreso mensual e historial crediticio. La salida `1` representa aprobacion preliminar y `0` representa rechazo.
